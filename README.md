node serve.js

## Publish on GitHub Pages

Public LinkedIn URL:

`https://ahm22529.github.io`

1. Create a **public** repo named `ahm22529.github.io` on https://github.com/ahm22529
2. Push this folder to `main`
3. GitHub → Settings → Pages → Deploy from branch `main` / `/ (root)`
4. Add the URL on LinkedIn: Contact info → Website, and Featured
